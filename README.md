# 応用情報技術者試験 科目A対策

スマホ・PCのブラウザで使える、応用情報技術者試験 科目A（午前）の学習アプリです。

**https://ayatakahashi0129.github.io/ap-study/**

- 過去問 918問（平成25年〜令和3年の春期・秋期）と新傾向オリジナル問題 78問のテスト・模擬試験
- 暗記カード 502語、用語集
- 要点解説 59テーマ（図解・たとえ話・ひっかけ注意）
- 学習記録はブラウザ内（localStorage）に保存

過去問の解説は参考書・解説集の文章のため、合言葉で暗号化して収録しています（合言葉を知っている人だけが表示できます）。

過去問題の出典：独立行政法人情報処理推進機構（IPA）応用情報技術者試験 午前問題

## 構成

- `index.html` … 公開版（GitHub Pages で配信）。`app_src/tools/build.py` で生成
- `app_src/` … アプリ本体とデータ、生成スクリプト（詳しくは [app_src/README.md](app_src/README.md)）

問題の元データ（PDF から抽出したもの）と合言葉はリポジトリに含めていません。
