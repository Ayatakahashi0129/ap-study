# 応用情報技術者試験 科目A・B対策

スマホ・PCのブラウザで使える、応用情報技術者試験 科目A（午前）・科目B（午後）の学習アプリです。

**https://ayatakahashi0129.github.io/ap-study/**

- 過去問 1576問（平成25年〜令和7年の春期・秋期）と新傾向オリジナル問題 78問のテスト・模擬試験
- 科目B（午後）188問（平成25年春〜令和7年秋の17回分）：問題冊子の画像と解答用紙。選択式は自動採点、記述式は解答例で自己採点。出題趣旨・採点講評つき
- 暗記カード 502語、用語集
- 要点解説 59テーマ（図解・たとえ話・ひっかけ注意）
- 学習記録はブラウザ内に保存し、Googleログインで端末間に同期（Firebase）

平成25年〜令和3年の過去問の解説は参考書・解説集の文章のため、公開版には含めず、Firebase に置いて作者のアカウントでログインしたときだけ表示します。

過去問題の出典：独立行政法人情報処理推進機構（IPA）応用情報技術者試験 午前・午後問題（解答例・出題趣旨・採点講評を含む）

## 構成

- `index.html` … 公開版（GitHub Pages で配信）。`app_src/tools/build.py` で生成
- `app_src/` … アプリ本体とデータ、生成スクリプト（詳しくは [app_src/README.md](app_src/README.md)）

問題の元データ（PDF から抽出したもの）はリポジトリに含めていません。
